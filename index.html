Это приложение используется для создания, планирования и публикации контента в Pinterest.

Какие данные мы можем обрабатывать

Приложение может обрабатывать технические данные, необходимые для работы интеграции с Pinterest, включая идентификаторы аккаунта, данные авторизации и информацию, необходимую для публикации контента.

Как используются данные

Данные используются только для авторизации, публикации контента, управления публикациями и базовой аналитики, если она доступна.

Передача данных третьим лицам

Мы не продаём персональные данные третьим лицам. Данные могут передаваться только сервисам, необходимым для работы приложения и API Pinterest.

Хранение и защита данных

Мы принимаем разумные меры для защиты данных от несанкционированного доступа, изменения или удаления.

Права пользователя

Пользователь может запросить удаление или уточнение данных, связанных с использованием приложения.
